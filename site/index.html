Type in a Steam profile. I read its public library and draw the time: one rectangle per game, area proportional to hours. Every game gets a page of its own, and the most played ones get a themed one.

    A vanity name, a steamID64 or the full URL all work. The profile needs Game details set to public - that is the Steam setting that releases the game list.

      That is the shape of a Steam library drawn to scale: one rectangle per game, area proportional to hours. Type a profile in and the rectangles get names, hours and a page each.

      One lookup, and the library comes apart into the pages it was always made of.

      What a profile turns into

      • 01
        The whole library, to scale Every game that was ever launched, one rectangle each, area proportional to hours. The long tail folds into one block and says how many it holds.
      • 02 One game, your record of it Achievements ranked by how rare they are, the ones still locked, the year each one was unlocked, and the hours split by the system you played on.
      • 03 One year of it What was put down that year and what was unlocked during it, in the order it happened.
      • 04 The pile Everything owned and never launched, searchable, with what it cost. The number nobody asks for and everybody reads twice.
      • 05 The badges, and what the rest would cost Every trading-card badge this library has made, the sets it has not, and what one of each missing card goes for on the market today.
      • 06 Two libraries at one scale Both maps drawn against the same hour, the games the two have in common, and who put the time in where. Nothing is scored: the numbers are only set beside each other.
      • 07 A picture to take away A bar chart, a badge, a banner, a card of this library against another, a full-size Steam artwork. Each one as an address that stays current, or as a file that never changes again.
      • 08 Every id the account has SteamID64 in decimal and in hex, STEAM_1 and STEAM_0, the invite code, the FiveM identifier, and the five addresses that all open the same profile. Arithmetic on a number already resolved, not a second request.
      • 09 A game with nobody attached The same care, without a profile in it: global achievement rarity, who is playing right now, the review split, the news and the current price.

      Every game gets a page of its own

      157 games have one built out of that game's own interface: the post-match scoreboard for Dota 2, the buy menu for Counter-Strike, motorway signage for Euro Truck Simulator. Everything else gets the generic page, which is still the whole record - achievements by rarity, who is playing right now, reviews, news and what it costs today.

      A lookup is one way in and not the only one. Everything below this line needs no profile typed and names nobody.

      The chart, as an address

      Every profile page carries a generator: a bar chart, a badge, a banner, a card against another library, a full-size Steam artwork. Each one is an address that redraws itself when the hours move, or a file that never moves again. Made for a README, a forum post or a Steam profile.

      Five repositories, all public, all MIT. The site is one of them and not the largest.

      The parts it is made of

      • The site The pages, the drawings and the field you type into: everything your browser runs. Open, MIT, and the same checkout anybody who wants to change it works on. the repository ↗
      • The service Python and the standard library, and nothing else. It reads Steam, caches what it may, draws the images, and answers every call these pages make. the repository ↗
      • The extension One Manifest V3 source tree for Chrome and for Firefox. It runs on a store page and on a profile page and nowhere else, with no cookie and no sign-in. the repository ↗
      • The strings Every word a reader sees, in a repository of its own, one file per language. A translation is a pull request there, and the build writes it into the two that serve it. the repository ↗
      • The player What plays a trailer on a game page, on its own: progressive MP4 and WebM, Steam HLS through MediaSource, keyboard, fullscreen and picture-in-picture. the repository ↗

      The three that do not change

      • No profile is stored. Every lookup goes to Steam live and is cached for 15 minutes, that is all.
      • Only what is public. If a profile hides its game details, Steam returns nothing and the page says so.
      • No sign-in. The API key stays on the server; your browser never sees it.
